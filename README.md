# CS 6330 Lim Voleak
This project examines how airport elevation, geographic position, and size  shape global air connectivity. Using integrated airline, airport, and route  data, it applies regression, classification, and clustering to investigate  whether physical infrastructure constrains an airport's role in the global  flight network.


## Key Findings - Geographic position explains **84.7%** of route distance variance, versus under **1%** from elevation alone — geography drives global flight network structure far more than infrastructure. - Just **92 airports** (out of thousands) account for **38.1%** of all global routes, revealing major hub-concentration risk.
