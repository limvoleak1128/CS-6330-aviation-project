# CS 6330 — Global Aviation Infrastructure Analysis
### Lim Voleak

This project investigates global aviation through the lens of physical
infrastructure, asking whether features like airport elevation, size, and
geographic position explain how the global flight network is structured.
Using integrated airline, airport, and route data, it applies regression,
classification, and clustering to test whether physical infrastructure
constrains an airport's role in the network.


## Key Findings

- **Geography, not elevation, drives route structure.** Geographic position explains 84.7% of route distance variance, versus under 1% from elevation alone.
- **Aviation is highly concentrated.** Just 92 airports account for 38.1% of all global routes.
- **Size labels don't reflect operational reality.** Many "large" airports serve fewer routes than some "medium" ones.
- **Basic infrastructure data predicts route type.** Geographic and infrastructure features alone predict domestic vs. international routes with 74% accuracy.
